==========================================
   极简虚拟手柄 - 电脑端服务使用说明
==========================================

1. 如何运行：
   - 双击运行目录下的 pc_server.exe。
   - 如果系统弹出 Windows 防火墙警告，请务必勾选“专用网络”并点击“允许访问”。

2. 手机 APP 如何连接：
   - 查看 pc_server.exe 窗口中显示的“📍 电脑局域网 IP”。
   - 在手机 APP 的 IP 地址栏填入该地址（例如 192.168.1.5）。
   - 端口号保持默认值 8888 即可。
   - 点击“连接电脑”，直到显示“✅ 已连接”。

3. 键盘映射规则：
   - △ (Triangle) -> 键盘 I
   - ▢ (Square)   -> 键盘 J
   - ✖ (Cross)    -> 键盘 K
   - ○ (Circle)   -> 键盘 L

4. 测试步骤：
   - 成功连接后，在电脑上打开一个记事本。
   - 按下手机上的四个大按钮，观察记事本是否自动输入 i, j, k, l。

5. 连接失败常见检查：
   - 手机和电脑是否连接在同一个 Wi-Fi 网络？
   - 电脑 IP 是否填写正确？
   - 电脑防火墙是否允许了 pc_server.exe 访问网络？
   - 如果电脑 IP 变了，需要更新手机里的 IP。

6. 如何退出：
   - 直接关闭 pc_server.exe 窗口，或者在窗口内按 Ctrl+C。
   - 程序会自动释放所有已按下的键盘按键，请放心。
==========================================
